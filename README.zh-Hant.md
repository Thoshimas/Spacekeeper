# Spacekeeper · 空間管家 1.0.0

Windows 10/11 本機硬碟空間管理工具，採用暖米色介面。提供英文與繁體中文，磁碟資料保留在本機，無雲端帳號、追蹤分析或遠端字型。

[English](README.md) · [建置及 GitHub 發布說明](BUILDING.md) · [驗證紀錄](VERIFICATION.md)

## 安裝與使用

1. 從 GitHub Releases 下載 **Spacekeeper-Setup-1.0.0-x64.exe**。開頭語言視窗預選 English；選中文（繁體）並按 OK 後，整個精靈會使用繁體中文。
2. 選擇只為自己或所有使用者安裝，再選安裝磁碟／資料夾與桌面、開始功能表捷徑。所有使用者安裝需要自行確認 Windows UAC。
3. 安裝後雙擊 **Spacekeeper.exe** 或捷徑，不需要 CMD。介面會以 Edge 應用程式視窗開啟，無 Edge 時使用預設瀏覽器。
4. 選擇磁碟或資料夾開始掃描；資料夾選擇視窗會在開啟期間保持最上層。
5. 透過大小或清理優先度排列地圖與清單。成功改名、移動或回收後，沿用現有索引更新統計與排序，不遞迴重掃整個磁碟。外部程式造成的變更仍須手動重新掃描。
6. 用完按「結束應用程式」。只關閉視窗會留下本機服務；重新開啟同一安裝位置的 EXE 會重用服務與掃描。

需要 64 位元 Windows 10/11、Windows PowerShell 5.1、.NET Framework 4.x 與可用的瀏覽器。安裝版內含 Node.js 與已編譯掃描器，不需另行安裝開發工具。首次預設英文；安裝與程式內主動選擇的語言會保存。

## 保護與限制

- Windows、開機、復原、分頁、已安裝程式、重要 AppData 設定及程式本身採固定保護，仍可瀏覽內容。AppData 不會整包開放修改；辨識出的 Local 快取與個別 Temp 項目可逐項檢查。
- 允許管理的項目可重新命名、移動或送到回收筒。操作前檢查目標，要求輸入精確原始名稱，並再次檢查；票證兩分鐘內有效且只能使用一次。
- 保護規則無法辨識所有應用程式相依關係或重要個人資料；可管理不代表一定可刪。管理員模式仍遵守同一組保護規則，不繞過 UAC、不修改 ACL、不接管所有權。
- 顯示檔案邏輯大小，並非實際配置空間或保證可釋放容量。硬連結可能重複計算；重解析點、連結與部分雲端佔位資料會略過。錯誤與略過原因會保留，結果可能不完整。
- **送入回收筒通常不會立刻釋放空間。** 請自行檢查回收筒後決定是否清空；本程式不清空，也不在失敗時改成永久刪除。
- 跨磁碟移動可能是複製後移除；中斷時請檢查兩端，沒有自動回復或覆蓋同名項目的承諾。檔案操作遇到連線結果不明時不會自動重送。
- 讀取查詢可有限重試；本機連線紀錄可協助查看原因。服務只監聽隨機的 127.0.0.1 連接埠，使用工作階段權杖、來源檢查與靜態檔案白名單。

## 偏好、更新與移除

安裝版偏好、操作與啟動資料保存在 `%LOCALAPPDATA%\Spacekeeper\Installs\<安裝位置識別碼>`，不需要寫入 Program Files。原始碼版在程式旁建立紀錄；這些本機資料不應上傳 GitHub。

升級前先從程式內結束舊版，再選原安裝資料夾。可由 Windows 已安裝的應用程式或 **Uninstall.exe** 移除。解除安裝拒絕中斷處理中的檔案操作；只移除已知程式檔案及所屬捷徑，保留額外放入的檔案與個人偏好／紀錄。

EXE 尚未簽署發行者憑證，Windows 可能顯示未知發行者。真實 UAC、所有使用者安裝、跨磁碟及 Windows 10 實機的完整流程尚未在相應環境完成實測；詳見驗證紀錄。

## 原始碼與授權

安裝 Node.js 22 以上後，在原始碼資料夾執行 `node server.mjs`；沒有 npm 外部套件。原始碼不附 Node 執行檔、已編譯 EXE 或建置暫存。`Build-Native.ps1` 可編譯原生元件；`Build-Installer.ps1` 可建立完整安裝包；步驟見 BUILDING.md。
